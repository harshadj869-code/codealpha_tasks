🚗 About CarPredict AI

Machine Learning based car price prediction system

🎯 Project Objective

CarPredict AI is a Machine Learning application designed to estimate the selling price of a used car based on important vehicle characteristics.

🤖 Machine Learning Models

  • Linear Regression
  • Random Forest Regression

🛠 Technologies Used

Python Pandas NumPy Scikit-learn Flask HTML CSS Chart.js

📊 Prediction Features

  • Car Year
  • Present Price
  • Driven Kilometers
  • Fuel Type
  • Selling Type
  • Transmission
  • Previous Owners

⚙️ Application Features

  • Machine Learning price prediction
  • Model performance dashboard
  • Prediction analytics
  • Prediction history
  • Search and filtering
  • Input validation
  • Responsive web interface
